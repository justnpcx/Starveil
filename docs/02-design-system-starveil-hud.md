# 02 · 设计系统定义（Starveil · 03 苹果毛玻璃）

> **本文是 Starveil 全部 UI 的唯一真理源。** 写 UI 时有疑问先查本文；本文与代码冲突时，以本文为准并同步修改代码。
> 命名规则：Compose 引用名 = Token 名（如 `StarveilColors.accent`）；**禁止在 Screen 里写裸色值或裸字号**，`Color(0xFF…)` 只允许出现在 `core/ui/theme/Palette.kt`。
> 历史：HUD 青蓝辉光（2026-10 前）→「曜」深空曜黑（0.8.0–0.8.2，因"太刺眼"被用户否决）→ **本版 03 苹果毛玻璃**（2026-10-25 起唯一执行依据）。v1「浅色奢华」、v2「双生主题」、07 融合版均已作废。

---

## 1. 设计语言陈述

**一句话**：浅色毛玻璃底、材料分层抬升、单支克制强调色、无发光——高级感靠分层、留白与秩序，不靠黑暗与光晕。

| 关键词 | 含义 | 落地 |
|---|---|---|
| **Material（材料）** | 层次来自"面"，不来自"光" | 底面渐变 + 68% 白卡片 + 1dp 白高光边，三层，越上层越亮 |
| **Restraint（克制）** | 强调色是预算，不是装饰 | 单支蓝 `#0071E3`，每屏 ≤3 处；永不大面积填充 |
| **Calm（不刺眼）** | 最大对比只出现在最该被看见的地方 | 正文 `#1D1D1F` 对底 14.3:1，而非纯黑配纯白的 21:1；无发光环 |

**三条"不要做"**：

1. **不要纯黑底 + 纯白字拉满**，不要发光环、外发光、重阴影。
2. **不要把强调色当填充**：不做强调色按钮、不做强调色色块；它只做线、点、字。
3. **不要卡中套卡**。一张卡 = 一个分组；卡内分隔只用 `hairline`。

## 2. 色彩 Token

| Token | 值 | 用途 |
|---|---|---|
| `bg` | `#E9EDF2` | 页面底色（渐变之下的基色） |
| `bgTop` / `bgMid` / `bgBottom` | `#E8EEF5` / `#EEF3EE` / `#F3ECE4` | 160° 氛围渐变（冷→暖） |
| `washes` | 蓝 `rgba(90,160,255,.28)`、绿 `rgba(80,210,170,.22)`、琥珀 `rgba(255,170,90,.20)` | 三处扁平椭圆晕染：12%/6%、88%/30%、70%/92% |
| `surfaceGlass` | `rgba(255,255,255,.68)` | 玻璃卡、弹层 |
| `surfaceThin` | `rgba(255,255,255,.55)` | 搜索框、旗标、小凹槽 |
| `surfaceChrome` | `rgba(255,255,255,.60)` | 底部导航（叠在 `bg` 上，见 §6 降级） |
| `surfaceSolid` | `#F6F8FA` | 浮在遮罩上的面：对话框、菜单、底部弹层 |
| `glassBorder` | `rgba(255,255,255,.75)` | 卡片 1dp 高光描边 |
| `hairline` | `rgba(255,255,255,.75)` | 卡内分隔、导航顶线 |
| `ink` | `#1D1D1F` | 主文字 |
| `ink2` | `rgba(29,29,31,.62)` | 次级文字（Demo 为 .60，抬到 .62 才过 4.5:1） |
| `ink3` | `rgba(29,29,31,.48)` | 三级文字/占位/未选图标（Demo .42，抬到 .48 得 3.06:1） |
| `accent` | `#0071E3` | 唯一强调色：选中标记、开关、状态点、圆环 |
| `accentText` | `#0066CC` | 强调色**文字**（`#0071E3` 对底 4.01:1，做正文不够） |
| `ok` | `#1D7A3A` | 在线/健康（文字与点共用，4.58:1） |
| `warn` | `#AC4D00` | 告警（Demo 未出现，用户补定，4.68:1） |
| `err` | `#E5484D` | 失败：状态点、曲线丢包点、阻断环 |
| `errText` | `#BE3238` | 失败**文字**（`#E5484D` 做正文只有 3.33:1） |
| `shadowTint` | `#1F2687` | 所有阴影的色相；卡片 7%、FAB 10% |

派生：

- `StarveilColors.accentWash` = `accent` 10%，选中行底色，**唯一允许的着色填充**。
- `StarveilColors.curveFillAlpha` = 14%，健康曲线填充（向下淡出到 0，见 §5）。
- `StarveilColors.ringIdle` = `ink3`。

对比度（`ContrastTest` 断言）：`ink`/`ink2` 在 `bg` 与 `surfaceGlass` 上 ≥4.5:1；`accentText`/`ok`/`warn`/`errText` 作为文字 ≥4.5:1；`accent`/`err` 作为图形 ≥3:1；`ink3` 记录在案（3.06:1，承意图形下限）。

## 3. 字体与字阶

无衬线一体，技术标注用系统等宽；**不引入衬线字体**，不外置字体文件（零体积增量）。

| Token | 规格 | 用途 |
|---|---|---|
| `display` | Light 54sp | 速率大数字 |
| `ringWord` | Light 34sp | 圆环中心状态词 |
| `title` | 28sp | 页面标题 |
| `headline` | 17sp | 卡片标题、行主文 |
| `body` | 15sp | 正文 |
| `label` | 13sp | 副文、说明 |
| `tech` | 等宽 11sp | 标签、单位、组标题 |
| `numInline` | 等宽 13sp | 行内数字（延迟、计数） |

间距阶梯：4 / 8 / 12 / 16 / 24 / 32 / 48；页面边距 24dp；8dp 网格。

## 5. 页面

**首页**：圆环 240dp / 4dp 环宽，**全状态位置尺寸固定**；已连接 = `accent` 细线环（**无光晕**），未连接 = `ink3`，连接中 = `accent` 环 + 扫光弧（弧线必须画在环上），告警 = `warn`，阻断 = `err`。速率两列中轴对称、不装卡。当前节点卡（国旗 + 名称 + 徽标 + 延迟）与节点健康卡（1.5dp `accent` 曲线 + 14% 淡出填充）各一张玻璃卡。页底留白 32dp。

**节点页**：标题 + 刷新/更多线性图标；`surfaceThin` 胶囊搜索框；分组芯片行；**整列一张玻璃卡**，行间 `hairline`。行：状态点 8dp → 国旗 → 名称（单行省略）→ 第二行 分组 · 协议（等宽） · 地址；右端延迟与首行共基线。选中行 = `accentWash` + 左缘 2dp `accent`。长按为底部弹层（Edit 第一）。列表底部留白 96dp。

**规则页**：预设三行 + 去广告开关 + 入口行组在同一张玻璃卡；单选标记见 §4。最近流向一张玻璃卡：规则名等宽、右端计数 `numInline`、直连 `ok` / 代理 `accentText`。

**日志页**：全量等宽 12.5sp / 行高 19，裸底不装卡、行间无分隔线。级别只用文字色：DEBUG `ink3`、INFO `ink2`、WARN `warn`、ERROR `errText`。复制为 `accentText` 文字按钮。

**设置页**：组标题 `tech` 大写 `ink2`；组 = 一张玻璃卡，行间 `hairline`，组间 32dp。无"外观"组（单主题，不切换）。

## 6. 工程约束

- **毛玻璃**：Compose 没有原生背景模糊，`Modifier.blur` 模糊的是自身内容而非身后，三方库禁用。落地方式：卡片用 68% 白叠在**静态**氛围底上（底是平滑渐变，等效于把底模糊后透上来）；**导航条**下面会滚过文字，按降级条款用 `bg` + `surfaceChrome` 两层实面。
- **性能**：渐变整页只画一次；卡片阴影是 Compose 原生 elevation；动效 240–300ms easeOut，圆环连接成功扫光一次，禁止弹簧过冲。
- **可访问性**：正文 ≥4.5:1，承意图形 ≥3:1；点击域 ≥48dp。
- **例外**：桌面小组件（`StarveilWidget`）是 RemoteViews 树，读不到 CompositionLocal，色值按本表**解析后**写死并注明来源。
